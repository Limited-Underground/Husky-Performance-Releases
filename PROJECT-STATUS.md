# Husky Performance — Project Status

Updated: October 11, 2026

Husky Performance is publicly released, full working software, free for personal and business use. No purchase, subscription, activation key or expiry is required. Source remains private and proprietary.

## Current release

[Husky Performance 1.0.2](https://github.com/Limited-Underground/Husky-Performance-Releases/releases/tag/v1.0.2) is available as a [Windows x64 installer](https://github.com/Limited-Underground/Husky-Performance-Releases/releases/download/v1.0.2/Husky-1.0.2-win-x64.msi) and [portable ZIP](https://github.com/Limited-Underground/Husky-Performance-Releases/releases/download/v1.0.2/Husky-1.0.2-win-x64.zip). Version notes and checksums are on the release page. The package is unsigned.

We address reported bugs and continue improvements through ongoing engineering and testing. Version notes describe changes, fixes and known issues. New builds receive separate version numbers and downloads.

## Feedback

Personal users and businesses are welcome to report problems, confusing behavior and workflow needs. Feedback is voluntary. See [Feedback](TESTING-PARTNERS.md) for helpful details and privacy precautions. Nothing is uploaded automatically.

Versions 1.0.0 and later have no expiry. Older 0.9.1 files retain their original five-day evaluation behavior. Historical packages remain available; use the current release for current features and fixes.

# Husky Performance

Husky Performance is publicly released, full working Windows software for automotive log analysis and related shop workflows. It is free for personal and business use, with no purchase, subscription, activation key or expiry.

The application includes its Windows x64 runtime; no separate .NET or PowerShell installation is required. For portable use, extract the complete ZIP and run VehicleData.Desktop.exe. Keep Husky.Maintenance.exe with the application for Recovery & Rollback.

This package is unsigned. Windows may display an unknown-publisher warning. Verify the download against the checksums on the release page.

## Feedback and updates

We address bugs as they are reported and continue to improve performance, feedback and stability through ongoing engineering and testing. Feedback is voluntary and does not affect free access. ## Your data

Husky uses local encrypted storage. Nothing is uploaded automatically. Keep backups and original logs. Review reports, exports, support packages and feedback files before sharing them; remove private customer and vehicle information, keys and credentials.
